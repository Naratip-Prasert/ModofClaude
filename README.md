# ModofClaude 🐘🐈

ม็อด (plugin) สำหรับ [Claude Code](https://claude.com/claude-code) ที่ทำมาเพื่อคนไทย: ช่วยเขียนพรอมต์ภาษาไทยให้เก่งขึ้น แต่งหน้าจอให้น่าใช้ และมีแมวส้มคอยเป็นเพื่อน

> โครงการชุมชนที่ไม่เป็นทางการ ไม่เกี่ยวข้องกับ Anthropic

## ติดตั้ง

```bash
claude plugin marketplace add Naratip-Prasert/ModofClaude --scope user
claude plugin install thai-prompt-kit@modofclaude --scope user
claude plugin install thai-vibes@modofclaude --scope user
claude plugin install orange-cat@modofclaude --scope user
claude plugin install thai-weather@modofclaude --scope user
```

ติดตั้งเสร็จแล้วให้ปิดและเปิด Claude Code ใหม่ อัปเดตเป็นเวอร์ชันล่าสุดด้วย `claude plugin marketplace update modofclaude` แล้ว `claude plugin update <ชื่อม็อด>@modofclaude`

## ม็อดในชุดนี้

### ✍️ thai-prompt-kit: ชุดเครื่องมือเขียนพรอมต์ภาษาไทย

**ดาวให้คะแนนพรอมต์สดขณะพิมพ์** บอกว่าพรอมต์ขาดอะไร และขึ้นเองเมื่อเริ่มพิมพ์ ไม่ต้องใช้คำสั่ง

ในแอป Claude Desktop ดาวจะเป็นแถบใต้แถบ context:

```
✍️ สั่งงาน ★★★☆☆ 3.5  ✓เป้าหมาย ✓บริบท ◐ข้อจำกัด ✗รูปแบบ ✓รายละเอียด
💡 บอกรูปแบบคำตอบ เช่น "สรุปเป็นข้อๆ" หรือ "ตอบเป็นภาษาไทยสั้นๆ"
```

ใน terminal และ VS Code ดาวจะอยู่ท้ายบรรทัดคำแนะนำใต้ช่องพิมพ์ และแสดงเฉพาะข้อที่ยังขาด

```
✍️ สั่งงาน ★★★☆☆ 3.5 ✗รูปแบบ ◐ข้อจำกัด
```

**แถบ context ในตัว** เหนือช่องพิมพ์จะมีแถบแสดงการใช้ context window แยกตามหมวด และเวลาที่เหลือของ prompt cache ส่วนดาวจะอยู่ใต้แถบนี้ในแถบเดียวกัน ซ่อนหรือแสดงได้ด้วย `/th-context` ส่วนนี้ดัดแปลงจาก [context-bar](https://github.com/Boom-Vitt/claude-mods-boombignose) ของ Boom-Vitt (MIT License)

> พื้นที่เหนือช่องพิมพ์แสดงได้ทีละม็อดเท่านั้น ถ้าติดตั้ง context-bar ไว้ด้วย อาจมีตัวใดตัวหนึ่งไม่ขึ้น ให้ปิด context-bar ด้วยคำสั่ง `claude plugin disable context-bar@claude-mods-boombignose`

- ✓ มีครบ · ◐ มีครึ่งเดียว · ✗ ยังขาด · – ไม่จำเป็นสำหรับพรอมต์ประเภทนี้
- **ตัดคำภาษาไทย** ก่อนให้คะแนน คำที่หน้าตาคล้ายกันจึงไม่ทำให้ได้คะแนนผิด เช่น "ถูกต้อง" ไม่นับเป็นข้อจำกัด "ทำไม" ไม่นับเป็นการสั่งงาน
- **รู้คำที่พิมพ์ผิด** ถ้าวรรณยุกต์ผิดหรือขาดไป 1 ตัวอักษร ก็ยังอ่านออก เช่น ต้อการ หรือ ต่องการ → ต้องการ
- **ดูรูปประโยค** คำสั่งต้องมีสิ่งที่จะทำ ข้อห้ามต้องมีสิ่งที่ห้าม รูปแบบคำตอบต้องอยู่ในรูป "ตอบเป็น…"
- **แยกประเภทพรอมต์** ได้แก่ สั่งงาน · คำถาม · คำสั่งสั้น · ตรวจ/รีวิว แต่ละประเภทนับเฉพาะข้อที่จำเป็น คำถามไม่ต้องมีข้อจำกัด คำสั่งอย่าง "รันเทสต์" ไม่ต้องบอกรูปแบบคำตอบ
- ให้คะแนนในเครื่องทั้งหมด และไม่แก้ไขพรอมต์ของคุณ

| คำสั่ง | ทำอะไร |
|---|---|
| `/th-better <คำขอสั้นๆ>` | ขยายคำขอสั้นๆ ให้มี เป้าหมาย · บริบท · ข้อจำกัด · เกณฑ์ว่าเสร็จ แล้วลงมือทำ |
| `/th-explain <เรื่อง>` | อธิบายโค้ดหรือแนวคิดแบบเข้าใจง่าย มีตัวอย่างเปรียบเทียบกับชีวิตจริง |
| `/th-plan <งาน>` | วางแผนเป็นขั้นตอนก่อนลงมือ (ยังไม่แก้ไฟล์) |
| `/th-review` | รีวิวโค้ดที่เปลี่ยน เรียงปัญหาตามความรุนแรง |
| `/th-fix <อาการ>` | ไล่หาสาเหตุบั๊กทีละขั้น แล้วแก้ที่ต้นเหตุ |
| `/th-commit [en\|th]` | เสนอข้อความ commit (ไม่ commit เอง) |
| `/th-coach on\|quiet\|off` | เปิดหรือปิดแถบดาว (`quiet` = ไม่แสดงเคล็ดลับ) ไม่ใส่ค่า = ดูสถิติ |
| `/th-coach why [ข้อความ]` | บอกว่าแต่ละข้อได้คะแนนเพราะเจอคำไหน |

**สไตล์คำตอบ "ครูไทย"** ตอบเป็นภาษาไทยที่อ่านง่าย ปิดท้ายด้วยหัวข้อ 💡 ได้เรียนรู้อะไร เลือกใช้ได้ที่การตั้งค่า output style

### 🐘 thai-vibes: แต่งหน้าจอ

- **แถบสถานะ** มีคำทักทายตามช่วงเวลา 🌅 ☀️ 🌇 🌙 วันที่ พ.ศ. นาฬิกา ข้างขึ้นข้างแรม 🌔 และ streak 🔥
- **`/vibes`** เปิดแผงด้านข้าง ในแผงมี
  - **ช้างน้อยที่ขยับได้:** กระพือหู พ่นน้ำ 💦 ทุกครั้งที่ทำงานเสร็จ และง่วง zZz ตอนดึกหรือเมื่อไม่ได้พิมพ์นาน
  - **🔥 Streak:** นับวันที่เขียนโค้ดติดต่อกัน จำข้ามวันได้ พร้อมสถิติสูงสุด
  - **ข้างขึ้นข้างแรม:** เช่น "🌔 ขึ้น 12 ค่ำ" และบอกวันพระโดยประมาณ (≈)
  - **สีประจำวันแบบไทย**
  - **สุภาษิตประจำวัน:** มีความหมายแบบโปรแกรมเมอร์ และกดสุ่มใหม่ได้
  - **สถิติของเซสชัน**
- **ธีมเทศกาล** เปลี่ยนเองตามวัน ได้แก่ ปีใหม่ 🎆 ตรุษจีน 🧧 วาเลนไทน์ 💝 สงกรานต์ 💦 วันแม่ 💙 ฮาโลวีน 🎃 ลอยกระทง 🪷 วันพ่อ 💛 และคริสต์มาส 🎄 ลองดูก่อนถึงวันจริงได้ด้วย `/vibes theme <ชื่อ>`
- **ข้อความระหว่างรอ Claude** แทน "Thinking…" เช่น "🍜 รอแป๊บ ต้มมาม่าอยู่" หรือ "🛺 ตุ๊กตุ๊กกำลังมา"
- **ฉลอง** 🎉 เมื่อทำงานครบรอบที่กำหนด และ **เตือนตอนดึก** 🦉 · ปิดการแจ้งเตือนได้ด้วย `/vibes-quiet`

วันลอยกระทง ตรุษจีน และวันพระคำนวณจากอายุดวงจันทร์ จึงอาจคลาดได้ 1 วัน

### 🐈 orange-cat: แมวส้มวิ่งเล่น

- **`/cat`** เปิดแผงที่มีแมวส้มวิ่งไปมา
- ทุกครั้งที่คำสั่งหรือเครื่องมือที่ Claude ใช้เกิด error แมวจะตกใจทำตาโต `( O.O )` แล้วกระโดด พร้อมนับว่า error ไปแล้วกี่ครั้ง

### ⛅ thai-weather: พยากรณ์อากาศในแถบสถานะ

```
☀️ 33° เชียงใหม่ · ☔ ฝน 60% 15 น. · PM2.5 28
```

- **แถบสถานะ:** แสดงอุณหภูมิ ท้องฟ้า โอกาสฝนตกที่สูงที่สุดใน 6 ชั่วโมงข้างหน้า (แสดงเมื่อ 40% ขึ้นไป) และฝุ่น PM2.5 ถ้าค่าเกิน 75 จะมี 😷
- **ไม่ต้องเปิด GPS:** บอกเมืองครั้งเดียวด้วย `/weather set เชียงใหม่` ใช้ชื่อภาษาไทยหรืออังกฤษก็ได้ ระบบจะหาในไทยก่อน ถ้าไม่เจอจึงหาเมืองในประเทศอื่น และจำเมืองไว้ในเครื่องคุณ
- **`/weather`:** ดูรายละเอียด ได้แก่ อุณหภูมิที่รู้สึก ความชื้น และควรพกร่มหรือไม่ · `/weather off` หรือ `/weather on` ปิดหรือเปิด
- **อัปเดตทุก 30 นาที** ใช้ข้อมูลจาก [Open-Meteo](https://open-meteo.com) ซึ่งฟรีและไม่ต้องใช้ API key (ข้อมูลใช้สัญญาอนุญาต CC BY 4.0)

ติดตั้งด้วย `claude plugin install thai-weather@modofclaude --scope user`

### 🐈 แถม: แมวใน prompt ของ PowerShell

ไม่ใช่ม็อดของ Claude Code แต่เป็นไฟล์ [powershell/orange-cat-prompt.ps1](powershell/orange-cat-prompt.ps1) ที่ทำให้ช่อง Terminal ของ PowerShell มีแมวนำหน้า และตกใจเมื่อคำสั่งที่คุณพิมพ์เองเกิด error

```
🐈 PS C:\project> aaa.py
...error...
🙀 meow! (1) PS C:\project>
```

ติดตั้งเองได้ใน 3 ขั้นตอน:

1. เปิดไฟล์ profile ด้วยคำสั่ง `New-Item -ItemType Directory -Force (Split-Path $PROFILE); notepad $PROFILE`
2. คัดลอกเนื้อหาทั้งหมดในไฟล์ [orange-cat-prompt.ps1](powershell/orange-cat-prompt.ps1) ไปวาง แล้วกด Save
3. ถ้า Windows ยังไม่อนุญาตให้รันสคริปต์ ให้รัน `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` ซึ่งเป็นการเปลี่ยนการตั้งค่าความปลอดภัยของเครื่อง จึงควรตัดสินใจเองก่อนรัน จากนั้นเปิดหน้าต่าง PowerShell ใหม่

ไฟล์นี้เปลี่ยนแค่หน้าตาของ prompt ไม่ต่อเครือข่าย ไม่เขียนไฟล์ และไม่รันอะไรเบื้องหลัง ถ้าไม่อยากได้แล้ว เปิด `notepad $PROFILE` แล้วลบตั้งแต่บรรทัด `>>>` ถึง `<<<` ออก

## ความเป็นส่วนตัว

ม็อดทั้งหมดไม่เรียกโมเดล และทุกตัวยกเว้น thai-weather ไม่ต่อเครือข่ายและไม่ส่งข้อมูลออกไปเอง

**thai-weather** ต่ออินเทอร์เน็ตไปที่ Open-Meteo เท่านั้น สิ่งที่ส่งออกไปมีดังนี้:
- ชื่อเมืองที่พิมพ์ใน `/weather set` ส่งครั้งเดียวตอนตั้งค่า
- พิกัดของเมืองนั้นที่ปัดเหลือทศนิยม 2 ตำแหน่ง (ราว 1 กม.) ส่งทุก 30 นาที

ม็อดไม่ใช้ GPS ไม่ดูตำแหน่งจาก IP และไม่ส่งพรอมต์หรือโค้ดของคุณออกไป Open-Meteo จะเห็น IP ของเครื่องคุณตามปกติของการต่ออินเทอร์เน็ต ปิดได้ด้วย `/weather off`

ตรวจสอบเองได้จากบรรทัด `calls:` ของคำสั่ง `claude plugin validate <ม็อด>` ม็อดที่ต่อเครือข่ายจะมี `$.http.fetch` อยู่ในบรรทัดนั้น
