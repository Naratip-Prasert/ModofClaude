# ModofClaude 🐘

ม็อด (plugin) สำหรับ [Claude Code](https://claude.com/claude-code) ที่ทำมาเพื่อคนไทย: ช่วยเขียนพรอมต์ภาษาไทยให้เก่งขึ้น และแต่งหน้าจอให้น่าใช้ขึ้น

> โครงการชุมชนที่ไม่เป็นทางการ ไม่เกี่ยวข้องกับ Anthropic

## ติดตั้ง

```bash
claude plugin marketplace add Naratip-Prasert/ModofClaude --scope user
claude plugin install thai-prompt-kit@modofclaude --scope user
claude plugin install thai-vibes@modofclaude --scope user
```

ติดตั้งเสร็จแล้วให้ปิดและเปิด Claude Code ใหม่

## ม็อดในชุดนี้

### ✍️ thai-prompt-kit: ชุดเครื่องมือเขียนพรอมต์ภาษาไทย

| คำสั่ง | ทำอะไร |
|---|---|
| `/th-better <คำขอสั้นๆ>` | ขยายคำขอสั้นๆ เป็นพรอมต์ที่มี เป้าหมาย · บริบท · ข้อจำกัด · เกณฑ์ว่าเสร็จ แล้วลงมือทำ |
| `/th-explain <เรื่อง>` | อธิบายโค้ดหรือแนวคิดแบบเข้าใจง่าย มีเปรียบเทียบกับชีวิตจริง |
| `/th-plan <งาน>` | วางแผนเป็นขั้นตอนก่อนลงมือ (ยังไม่แก้ไฟล์) |
| `/th-review` | รีวิวโค้ดที่เปลี่ยน เรียงปัญหาตามความรุนแรง |
| `/th-fix <อาการ>` | ไล่หาสาเหตุบั๊กแบบนักสืบ แล้วแก้ที่ต้นเหตุ |
| `/th-commit [en\|th]` | เสนอข้อความ commit ที่ดี (ไม่ commit เอง) |
| `/th-coach on\|quiet\|off` | โค้ชให้ดาวพรอมต์ ★★★☆☆ ในแถบสถานะ (ไม่ใส่ค่า = ดูสถิติ) |

**โค้ชพรอมต์** ให้คะแนนพรอมต์ทุกครั้งที่ส่ง 5 ดาวจาก: เป้าหมาย · บริบท · ข้อจำกัด · รูปแบบคำตอบ · รายละเอียด ถ้าได้ 2 ดาวหรือน้อยกว่าจะเด้งเคล็ดลับให้ การให้คะแนนทำในเครื่องทั้งหมด และไม่แก้ไขพรอมต์ของคุณ

**สไตล์คำตอบ "ครูไทย"** ตอบเป็นภาษาไทยที่อ่านง่าย พร้อมหัวข้อ 💡 ได้เรียนรู้อะไร เลือกใช้ได้จากการตั้งค่า output style

### 🐘 thai-vibes: แต่งหน้าจอ

- **แถบสถานะ** ทักทายตามช่วงเวลา 🌅 ☀️ 🌇 🌙 พร้อมวันที่ไทย พ.ศ. และนาฬิกา
- **`/vibes`** เปิดแผงด้านข้าง มีแถบสีรุ้ง ช้างน้อยเปลี่ยนสีทุกนาที สีประจำวันแบบไทย สุภาษิตประจำวันพร้อมความหมายแบบโปรแกรมเมอร์ (กดสุ่มได้) และสถิติเซสชัน
- **ฉลอง** 🎉 เมื่อทำงานครบ 5, 10, 25, 50, 100 รอบ
- **เตือนตอนดึก** 🦉 หลัง 23:00 เตือนให้พักสายตาชั่วโมงละครั้ง
- **`/vibes-quiet`** ปิด/เปิดการแจ้งเตือน

## ความเป็นส่วนตัว

ทั้งสองม็อดไม่เรียกเครือข่าย ไม่เรียกโมเดล และไม่ส่งข้อมูลออกไปเอง (ตรวจได้จากบรรทัด `calls:` ของ `claude plugin validate <ม็อด>`)

## พัฒนาต่อ

```bash
claude plugin validate .
claude plugin validate thai-prompt-kit
claude plugin validate thai-vibes
```

ต้องใช้ Claude Code เวอร์ชันที่รองรับปลั๊กอินแบบ hook module (ทดสอบ validate กับ 2.1.283)
