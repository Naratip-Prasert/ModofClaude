argument-hint: "[en | th]"
---

ดู `git status` และ `git diff --staged` (ถ้าไม่มีอะไร staged ให้ดู `git diff`) แล้วเสนอข้อความ commit

- ภาษา: $ARGUMENTS (ถ้าไม่ระบุ ให้ใช้ภาษาอังกฤษ)
- บรรทัดแรกไม่เกิน 72 ตัวอักษร ขึ้นต้นด้วยกริยารูปคำสั่ง เช่น Add / Fix / Update
- เว้นหนึ่งบรรทัด แล้วอธิบาย "ทำไม" ถึงเปลี่ยน ไม่ใช่แค่ "เปลี่ยนอะไร"
- ถ้าการเปลี่ยนแปลงปนกันหลายเรื่อง ให้แนะนำว่าควรแยกเป็นกี่ commit

แสดงข้อความในกรอบโค้ด แล้วถามก่อนว่าจะให้ commit เลยหรือไม่ **ห้าม commit เอง**
