argument-hint: "[ไฟล์หรือขอบเขตที่อยากให้ดู]"

รีวิวการเปลี่ยนแปลงโค้ดล่าสุด (ใช้ `git diff` และ `git diff --staged` ถ้าเป็น git repo) ขอบเขตเพิ่มเติม: $ARGUMENTS

ตรวจหา:
- 🐞 บั๊กหรือผลลัพธ์ผิด
- 🔒 ปัญหาความปลอดภัย (ความลับหลุด, input ที่ไม่ได้ตรวจ, SQL injection ฯลฯ)
- 🐢 ประสิทธิภาพที่แย่โดยไม่จำเป็น
- 🧹 โค้ดที่อ่านยากหรือซ้ำซ้อน
- 🧪 ส่วนที่ควรมีเทสต์แต่ไม่มี

รายงานเป็นภาษาไทย เรียงจากรุนแรงมากไปน้อย แต่ละข้อมี: ตำแหน่ง (`ไฟล์:บรรทัด`) · ปัญหา · ตัวอย่างสถานการณ์ที่พัง · วิธีแก้ที่แนะนำ

ห้ามแก้ไฟล์เอง ถ้าไม่พบปัญหาให้บอกตรงๆ ไม่ต้องหาเรื่องมาเติม
